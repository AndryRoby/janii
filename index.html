ARLingJanii

Archived experiment

Janii is closed.

Janii was a free Windows beta for wedding photographers, released on 4 Sep 2026. On one wedding, against one person's picks made as the client (a wedding Janii was tuned on), it matched 44.4 % of the picks, against 43.8 % by sharpness alone and 39.9 % by chance. That is not good enough for client work, so we stopped it.

No support and no further development. The source code has not been published. The beta ZIP stays on GitHub for anyone who already uses it; it was built on 4 Sep 2026, includes the Python engine as of that day under the same all-rights-reserved terms, and does not include later changes.
